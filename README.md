# NutriScan

A multimodal RAG-based food auditing system.

## Features
- Food label OCR and ingredient extraction
- Additive and allergen detection
- Nutrition analysis
- FSSAI number verification
- Evidence-grounded conversational food auditing

## Tech Stack
- Frontend: Next.js, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- OCR and ML: Python
- RAG: Qdrant and an LLM

## Project Structure
- frontend/: Web application
- backend/: API and business logic
- ml/: OCR and computer vision
- rag/: Retrieval and LLM pipeline
- data/: Sample and reference datasets
- docs/: Project documentation
